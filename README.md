# Pawform · 程序化宠物碗架生成器

纯前端的 3D 打印模型生成器：调参数 → 实时预览 → 导出可直接打印的 STL。
无后端、无构建步骤，打开网页就能用。

## 功能

- **12 款造型预设**：圆润叠圈 / 竹节 / 细密竖纹 / 极简圆筒 / 花瓣 / 波浪 / 菱格绗缝 / 波点 / 鱼骨纹 / 锥形 / 鹅卵石 / 旋纹
- **造型起伏**与**整体扭转**实时可调（轴对称造型会自动禁用扭转并给出说明）
- **名字刻印**：浮雕 / 凹刻，8 种字体、6 种装饰图形，位置与深度可调
- **尺寸全可调**：支架高度、碗口外径、嵌入直径、碗深、径向间隙、主体壁厚
- **毫米制 STL 导出**，几何水密，底部可开托盘与排水孔
- 设计可生成链接 / 分享码，打开即恢复全部参数

## 本地运行

浏览器不允许用 `file://` 直接加载 ES 模块，需要起一个静态服务器：

```bash
python3 -m http.server 8000
# 然后打开 http://localhost:8000/
```

macOS 用户也可以直接双击 `启动.command`（等价于上面的命令，且禁用了缓存）。

## 技术栈

- 原生 JavaScript + ES Module，无打包工具
- Three.js（`three.module.min.js` 为本地文件，不依赖 CDN）
- 几何由代码程序化生成：回转面 + 角向纹理函数，文字凸台是独立的圆角矩形板

## 目录

```
index.html            页面结构
style.css             样式
app.js                状态、几何生成、交互、导出
STLExporter.js        STL 导出器
three.module.min.js   Three.js 运行时
server.py             本地预览服务器（禁缓存）
启动.command          macOS 一键启动
```

## 说明

- 导出的是**外部支架**，不锈钢碗为独立标准件，不参与导出
- STL 内含两个壳体（支架 + 文字凸台），主流切片软件会自动合并
- 颜色仅用于屏幕预览，实物受耗材、光线与层纹影响
